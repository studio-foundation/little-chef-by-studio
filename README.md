# little-chef-by-studio

Generated from the `content` Studio template.

## Getting started

```bash
npm install
studio run content-creator --input "Write a blog post about..."
```

## Pipelines

- **content-creator** — Research and create content from a prompt

## Configuration

Set your API key:

```bash
studio config set provider anthropic --api-key $ANTHROPIC_API_KEY
```
